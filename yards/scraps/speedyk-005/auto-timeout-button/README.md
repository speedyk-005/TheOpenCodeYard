# Auto Timeout Button

- Status: Experimental
- Main Language: Python
- Accepting Contributions: No

---

## What it does

A button that auto-resets after 3 seconds using a daemon thread. CLI demo of timeout-based state management.

## How to use

```bash
python main.py
```

Press Enter to click the button. Wait 3 seconds and it resets.
