# HT Num Converter

- Status: Experimental
- Main Language: Python
- Accepting Contributions: Yes

---

## What it does

Converts numbers to Haitian Creole (Kreyòl) text. Handles 0 through billions.

## How to use

```bash
python main.py
```

Then type a number. Type `fen` to quit.

## Notes

Haitian Creole number system uses a base-10/vigesimal hybrid (e.g., `katreven` = 80, literally "four twenties").
