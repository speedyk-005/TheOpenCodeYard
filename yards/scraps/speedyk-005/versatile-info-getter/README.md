# Versatile Info Getter

- Status: Experimental
- Main Language: C#
- Accepting Contributions: Yes

---

## What it does

Parses name and age from a single input line (e.g., "Mark, 20") with validation. Re-prompts for any missing fields.

## How to use

```bash
dotnet run
```

Type your name and age, or just one of them. It'll ask for what's missing.

## Notes

Pure C# — no dependencies.
